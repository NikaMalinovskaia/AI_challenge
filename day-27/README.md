# День 27: Интеграция локальной LLM в веб-приложение (C# Code Reviewer)

Автономное веб-приложение для автоматической проверки C# кода на соответствие принципам ООП (инкапсуляция, правильное использование свойств вместо публичных полей) с использованием локальной языковой модели `qwen2.5` через Ollama.

---

## 🌟 Особенности проекта

- **100% Локальный контур:** Приложение работает полностью офлайн без обращения к облачным API, передача кода за пределы локальной машины исключена.
- **Минималистичная архитектура:** Реализовано на стандартной библиотеке Python без использования тяжелых веб-фреймворков (Flask/FastAPI/Django).
- **Автоматический запуск:** При старте сервера автоматически запускается экземпляр браузера с открытой страницей приложения.
- **Асинхронный UI:** Веб-интерфейс не блокируется при ожидании ответа от модели благодаря асинхронным HTTP-запросам (`fetch` API).

---

## 🏗️ Архитектура приложения

```
+------------------------+      HTTP (POST /review)      +------------------------+
|                        |  -------------------------->  |                        |
|  Браузер (HTML/JS UI)  |                               |  Python Backend        |
|  http://localhost:8080 |  <--------------------------  |  (http.server)         |
+------------------------+      JSON { result }          +------------------------+
                                                                     |
                                                                     | HTTP POST (prompt)
                                                                     v
                                                         +------------------------+
                                                         |  Ollama Service        |
                                                         |  qwen2.5 @ :11434      |
                                                         +------------------------+
```

1. **Frontend:** HTML5, CSS3 и JavaScript внедрены непосредственно в Python-скрипт.
2. **Backend:** Класс `ReviewHandler` наследуется от `http.server.SimpleHTTPRequestHandler` и обрабатывает:
   - `GET /` — отдаёт HTML-интерфейс.
   - `POST /review` — принимает фрагмент C# кода, оборачивает его в системный промпт эксперта по ООП и проксирует запрос в Ollama.
3. **LLM Engine:** Локальный сервер Ollama, выполняющий инференс модели `qwen2.5` по адресу `http://localhost:11434/api/generate`.

## 🚀 Инструкция по запуску

### 1. Предварительные требования

- Установленный **Python 3.8+**
- Установленная и запущенная **Ollama**
- Загруженная модель `qwen2.5`:
  ```
  ollama pull qwen2.5
  ```

### 2. Установка зависимостей

Приложению требуется только библиотека `requests` для отправки HTTP-запросов к Ollama:

```
pip install requests
```

### 3. Запуск приложения

Убедитесь, что сервер Ollama запущен, после чего выполните:

```
python app.py
```

При запускe скрипт:
1. Поднимет HTTP-сервер на `http://localhost:8080`.
2. Автоматически откроет вкладку в вашем браузере по умолчанию.

---

## 🧪 Пример использования

1. Вставьте C# код с нарушением принципов инкапсуляции:
   ```
   public class Account {
       public decimal balance;
   }
   ```
2. Нажмите кнопку **«Проверить код»**.
3. Локальная модель `qwen2.5` проанализирует код и вернёт структуру с замечаниями, оценкой и решением (например, заменой публичного поля на автосвойство `{ get; private set; }`).
