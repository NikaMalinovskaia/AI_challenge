# 👤 День 12: Персонализация ассистента

Модуль посвящен настройке индивидуального поведения модели поверх многоуровневой памяти. Ассистент адаптирует тон, глубину ответов, стиль и формат под конкретного пользователя, динамически подтягивая профиль (`long_term`) к каждому системному запросу.

---

## 🎯 Цели проекта
1. **Создание профиля пользователя:** Формализация параметров пользователя (роль, предпочтения в стиле, ограничения по формату).
2. **Интеграция в каждый запрос:** Автоматическое внедрение долгосрочного профиля в системный промпт LLM.
3. **Гибкое управление на лету:** Возможность менять параметры профиля прямо из сайдбара приложения через удобную форму ввода.
4. **Персистентность:** Сохранение настроек профиля и истории диалога в изолированных JSON-файлах.

---

## 🛠️ Архитектура и файлы проекта

* **`agent.py`** — Класс `PersonalizedAgent`, управляющий тремя уровнями памяти (`short_term`, `working`, `long_term`) и формирующий динамический системный промпт с учетом персонализации.
* **`app.py`** — Веб-интерфейс на базе **Streamlit**, включающий:
  * Выбор модели и настройку `temperature`.
  * Интерактивную форму обновления параметров профиля (`long_term`) на лету.
  * Панель мониторинга рабочей памяти задачи.
  * Кнопку полного сброса состояния.
* **`memory_storage_day12/`** — Директория персистентного хранения данных в формате JSON.

## 🚀 Быстрый старт

1. Установите зависимости:
   ```bash
   pip install streamlit openai
   ```
2. Убедитесь в наличии переменной окружения с вашим API-ключом:
```
export LITELLM_API_KEY="ваш_ключ"
```
3. Запустите приложение:
```
streamlit run app.py
```

### 🧪 Сценарий тестирования (Проверка персонализации)
1. Проверка работы дефолтного профиля (Senior Developer):
- Задайте технический вопрос (например: «Как обрабатывать исключения в асинхронном коде?»).
- Убедитесь, что ответ подан строго, профессионально, без лишней «воды», с использованием маркеров и лаконичного кода.
2. Проверка изменения профиля:
- В боковой панели через форму добавьте новый параметр: ключ — style, значение — объясняй как новичку, используя простые аналогии и дружелюбный тон.
- Задайте тот же вопрос повторно.
- Результат: Тон, формат и глубина ответов ассистента мгновенно изменятся в строгом соответствии с новым профилем.

Создан гибкий и адаптируемый AI-ассистент, подстраивающийся под индивидуальные требования пользователя на уровне системного контекста.
