# AI Challenge - Day 4

## Исследование параметра Temperature
Практическое задание по исследованию того, как изменение параметра temperature влияет на генерацию текста языковой моделью через корпоративный LiteLLM API.

## Суть задания

Выполнить один и тот же запрос при трех разных значениях параметра temperature:
* `temperature = 0` — детерминированный режим для максимальной точности.
* `temperature = 0.7` — сбалансированный режим для универсальных задач.
* `temperature = 1.2` — креативный режим для максимальной вариативности.

## Сравнить полученные ответы по:
* **Точности** (соблюдение структуры и логики запроса).
* **Креативности** (оригинальность метафор и образов).
* **Разнообразию** (лексический состав и словарный запас).

Сформулировать, для каких именно задач лучше подходит каждая настройка.

 ##Структура проекта

* `task_day4.md` — файл с условием выбранной задачи (объяснение концепции «Технического долга» для владельца бизнеса через строительную метафору).
* `main_day4.py` — основной скрипт на Python, который последовательно обращается к LiteLLM API при температурах 0, 0.7 и 1.2, а также автоматически генерирует аналитический отчет.
* `run_day4.sh` — bash-скрипт для настройки окружения и запуска эксперимента.
* `temperature_comparison.md` — итоговый Markdown-отчет с примерами ответов и выводами по их использованию (создается автоматически после запуска).

## Инструкция по запуску

1. Подготовка

Убедитесь, что у вас установлены необходимые библиотеки (например, `openai`):
```
pip3 install openai
```
2. Настройка ключа и модели
- Откройте файл run_day4.sh и впишите ваш личный ключ LiteLLM в переменную LITELLM_API_KEY.
- Откройте файл main_day4.py и убедитесь, что в переменной MODEL_NAME указана ваша разрешенная рабочая модель (например, glm-4.7-flash).

3. Запуск
- Выполните в терминале команду:
```
bash run_day4.sh
```
- После завершения работы скрипта в корневой папке появится файл temperature_comparison.md, содержащий примеры ответов с разной температурой, результаты их сравнения по точности, креативности и разнообразию, а также выводы по их практическому использованию.
