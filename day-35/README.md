# 🤖 Master AI Reviewer — Автономный AI-пайплайн проверки кода (День 35)

---

### 🎯 Какую задачу мы решаем?
Ручная проверка практических и лабораторных работ студентов по программированию (C# / ООП) требует огромных временных затрат преподавателя. При большом потоке работ сложно сохранять единообразие критериев, оперативно давать развёрнутую обратную связь и подробно разбирать ошибки каждого студента.

**Решение:** Автоматический CLI-пайплайн, который мгновенно забирает проект студента по ссылке с GitHub (или из локальной папки), сверяет весь код с методическими материалами курса и формирует структурированный Markdown-отчёт с детальным разбором, оценкой и примерами исправлений.

---

### 🧠 Как AI участвует в процессе?
AI выступает в роли **экспертного преподавателя-ментора**:
1. **RAG (Retrieval-Augmented Generation):** Скрипт подгружает в контекст модели локальный файл `criteria.md` (базу знаний с требованиями, задачами и критериями оценки).
2. **Контекстный анализ кодовой базы:** Локальная языковая модель `qwen2.5` (запущенная через `Ollama`) получает исходный код всех `.cs` файлов проекта, за раз оценивая логику, архитектуру классов, инкапсуляцию и соблюдение стандартов именования.
3. **Генерация обратной связи:** AI не просто ставит оценку от 1 до 5, а объясняет статус («зачтено» / «доработать»), указывает на отсутствующие классы и даёт готовые snippet-исправления проблемных мест.

## 🛠 Архитектура пайплайна
[GitHub URL / Локальный путь]
│
▼
prepare_target() ──► Клонирование / обновление через git clone (без API-токенов)
│
▼
scan_target_directory() ──► Рекурсивное обнаружение всех .cs файлов
│
▼
load_criteria() ──► Чтение критериев курса из criteria.md (RAG)
│
▼
run_ai_review() ──► Локальная LLM (qwen2.5 / Ollama)
│
▼
Output ──► Уникальный отчёт Review_Report_<имя_репозитория>.md

---

## 🚀 Особенности и преимущества

- **100% Приватность и Бесплатность:** Работает локально через `Ollama`, не требует платных облачных API и токенов.
- **Поддержка GitHub:** Динамически обрабатывает прямые веб-ссылки на репозитории и конкретные вложенные папки (например, `/tree/main/test`).
- **Сканирование всей структуры:** Объединяет все `.cs` файлы проекта в единый контекстный блок для сквозного анализа архитектуры.
- **Уникальные отчёты:** Динамически формирует имена отчётов (`Review_Report_<имя_репо>.md`), что исключает перезапись при пакетной проверке.
- **Удобный CLI:** Яркое ANSI-логирование статусов выполнения в терминале.

💻 Использование
