# День 26: Интеграция и запуск локальной LLM (Ollama)

Цель данного этапа — перенос инференса агента код-ревью на локальную инфраструктуру с использованием **Ollama** и модели **Qwen 2.5**. Это обеспечивает автономность работы, высокую скорость обработки запросов и защиту учебных данных студентов.

---

## 🚀 Архитектура и стек
* **Инфраструктура:** Локальный сервер Ollama (`http://localhost:11434`)
* **Модель:** `qwen2.5` (оптимизирована для задач анализа кода и генерации текста)
* **Язык реализации:** Python 3, библиотека `requests`
* **Автоматизация тестов:** Скрипт `test_local_llm.py` с замером времени ответа

---

## 🛠 Установка и запуск

1. Установите и запустите приложение **Ollama** [с официального сайта](https://ollama.com).
2. Загрузите и запустите локальную модель через терминал:
   ```bash
   ollama run qwen2.5
   ```
3. Убедитесь, что локальный HTTP API доступен (сервер поднимается автоматически при запуске приложения).

## 🧪 Тестирование и верификация (test_local_llm.py)
Для проверки работоспособности локальной модели и ее готовности к интеграции в пайплайн код-ревью был разработан автоматизированный тестовый скрипт, выполняющий три запроса разной сложности.
