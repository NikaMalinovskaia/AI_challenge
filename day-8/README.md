# 📊 AI Challenge — День 8: Трекер токенов и контроль контекста

Веб-приложение на базе **Streamlit** и **OpenAI API / LiteLLM**, реализующее детальный подсчет токенов (`tiktoken`), мониторинг лимитов контекстного окна модели в реальном времени, а также управление множеством независимых чатов.

---

## 📂 Архитектура проекта

Проект разделен на логические компоненты:
* **`agent.py`** (или `agent_2.py`) — класс `TokenAgent`, отвечающий за:
  * Точный подсчет токенов с помощью библиотеки `tiktoken` (кодировка `cl100k_base`).
  * Контроль лимитов контекста и перехват ошибок при превышении максимального объема.
  * Изолированное хранение каждого диалога в отдельном JSON-файле в директории `chats_storage_day8/`.
* **`app.py`** (или `app_2.py`) — пользовательский веб-интерфейс на **Streamlit** с боковой панелью управления лимитами, шкалой прогресса заполнения контекста, возможностью переключения/удаления чатов и экспандером детализации токенов для каждого сообщения.

---

## ✨ Ключевые возможности

1. **Точный подсчет токенов:** Динамический расчет веса каждого сообщения истории, нового запроса пользователя и ответа модели.
2. **Настраиваемый лимит контекста:** Интерактивный слайдер в сайдбаре позволяет гибко задавать лимит токенов модели (от 200 до 15 000) для тестирования переполнения.
3. **Прогресс-бар заполнения:** Визуальная шкала и метрики в сайдбаре мгновенно показывают текущую нагрузку на контекстное окно (История + Запрос).
4. **Защита от переполнения:** При превышении лимита агент блокирует отправку запроса и выводит детальную ошибку с разбивкой по токенам[cite: 3].
5. **Менеджер чатов:** Поддержка создания новых диалогов, переключения между ними и удаления ненужных сессий с сохранением данных на диск.
6. **Детализация токенов:** Раскрывающийся блок (`st.expander`) под каждым ответом модели показывает точное количество токенов запроса, истории, ответа и накопительный итог[cite: 4].

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей
Убедитесь, что у вас установлен Python (версии 3.9+), затем установите необходимые библиотеки:
```bash
pip install streamlit openai tiktoken
```
### 2. Настройка переменных окружения
Установите ключ доступа к API:
```
export LITELLM_API_KEY="ваш_api_key"
```

### 3. Запуск приложения
Запустите веб-интерфейс с помощью Streamlit (укажите имя вашего файла интерфейса, например app.py):
```
streamlit run app.py
```
После этого приложение откроется в браузере.

## 🧪 Как протестировать (Мануальный сценарий)
- Откройте приложение в браузере и выставьте в сайдбаре небольшой лимит модели (например, 500 токенов), чтобы быстро достичь порога переполнения.
- Отправьте несколько длинных сообщений подряд или скопируйте объемный текст.
- Обратите внимание на прогресс-бар и метрики в сайдбаре — они в реальном времени покажут рост объема токенов и процент заполнения окна.
- Когда суммарный объем (история + запрос) превысит установленный лимит, агент выдаст ошибку переполнения контекста (ValueError), а сайдбар зафиксирует критическое превышение.  
- Переключитесь на другой чат через боковую панель или создайте новый «✏️ Новый диалог», чтобы начать работу с чистым листом.
