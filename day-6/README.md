AI Challenge - Day 6

Эксперимент: Первый агент

Практическое задание по реализации простого автономного агента, инкапсулирующего логику запросов к LLM через корпоративный LiteLLM API.
🎯 Суть задания

Создать базового агента в виде отдельной программной сущности, которая:
* Принимает пользовательский запрос.
* Инкапсулирует в себе всю логику взаимодействия с API модели (подготовку сообщений, системные промпты, параметры).
* Отправляет запрос через HTTP-клиент (библиотеку `openai`) на корпоративный шлюз.
* Получает ответ и выводит его в интерфейсе (CLI).

Важное требование: агент должен быть отдельным классом или модулем, а не простым разовым вызовом функции.
📁 Структура проекта

* `agent.py` — класс агента, инкапсулирующий логику работы с LLM, системные настройки и вызовы API.
* `main_day6.py` — основной исполняемый файл, создающий экземпляр агента и запускающий диалог или тестовый запрос.
* `run_day6.sh` — bash-скрипт для быстрой настройки окружения и запуска.
* `agent_output.md` — итоговый отчет с результатами работы агента (создается автоматически).
🚀 Инструкция по запуску

1. Подготовка

Убедитесь, что у вас установлена библиотека `openai`:
```bash
pip3 install openai
```
2. Настройка ключа и параметров
Откройте файл run_day6.sh и впишите ваш личный ключ LiteLLM в переменную LITELLM_API_KEY.
Убедитесь, что в файле agent.py прописана ваша разрешенная модель (например, glm-4.7-flash).

3. Запуск
Выполните в терминале команду:
```
bash run_day6.sh
```
После запуска агент инициализируется как отдельная сущность, обработает тестовый запрос через API шлюза и выведет результат.
