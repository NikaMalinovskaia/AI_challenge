# 🤖 AI Challenge — День 6: Первый инкапсулированный AI-агент

Простой и эффективный веб-агент на базе **Streamlit** и **OpenAI API / LiteLLM**, реализующий концепцию инкапсуляции состояния и логики диалога внутри отдельного класса-сущности.

---

## 📂 Архитектура проекта

Проект разделен на логические компоненты:
* **`agent.py`** — класс `LLMAgent`, выступающий в роли изолированной сущности. Отвечает за:
  * Инициализацию клиента LLM (модель `glm-5.3-flash` / `glm-4.7-flash`, параметры `temperature`).
  * Инкапсулированное хранение истории сообщений (`self.messages`) вместе с системным промптом.
  * Обработку запросов (`chat`), отправку сообщений через API и откатку истории в случае сетевых сбоев[cite: 7].
  * Управление состоянием памяти (`reset_memory`)[cite: 7].
* **`app.py`** — пользовательский веб-интерфейс на **Streamlit**. Предоставляет чат-панель в реальном времени, боковую панель с настройками модели, кнопку сброса контекста и функцию экспорта диалога в файл отчета (`agent_output.md`).

---

## ✨ Ключевые особенности

1. **Инкапсуляция логики:** Вся работа с историей сообщений и API скрыта внутри класса `LLMAgent` — интерфейс взаимодействует с агентом исключительно через метод `.chat(user_message)`[cite: 7, 8].
2. **Интерактивная панель управления:** Возможность настройки модели и температуры генерации прямо из сайдбара с автоматической переинициализацией сессии.
3. **Безопасность контекста:** При возникновении ошибки API агент автоматически удаляет последнее сообщение пользователя из стека, предотвращая порчу контекста[cite: 7].
4. **Экспорт диалогов:** Функция сохранения текущей истории в формате Markdown (`agent_output.md`) одним кликом.

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей
Убедитесь, что у вас установлен Python (версии 3.9+), затем установите необходимые библиотеки:
```bash
pip install streamlit openai
```
### 2. Настройка переменных окружения
Установите ключ доступа к API (в коде предусмотрен дефолтный фоллбек для удобства тестирования)[cite: 7]:
```
export LITELLM_API_KEY="ваш_api_key"
```
### 3. Запуск приложения
Запустите веб-интерфейс с помощью Streamlit:
```
streamlit run app.py
```
После этого приложение откроется в браузере.

## 🧪 Мануальный сценарий проверки (для видео)
- Откройте приложение в браузере.
- Напишите агенту приветственное сообщение или задайте вводную (например: «Запомни секретный кодовок: Альфа-1»).
- Задайте уточняющий вопрос («Какой кодовок я попросил запомнить?») — агент корректно ответит, доказав, что память успешно инкапсулирована и сохраняется в рамках сессии.
- Проверьте работу кнопки «🔄 Очистить чат» в сайдбаре — история очистится, а агент вернется к исходному состоянию.
- Нажмите «🏁 Завершить диалог и сохранить», чтобы проверить генерацию и сохранение отчета в файл agent_output.md
