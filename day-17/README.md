# День 17: Кастомный MCP-сервер и инструменты валидации кода

Этот проект представляет собой развитие FSM-агента (**AI Quality Architect**), интегрированного с собственным **Model Context Protocol (MCP)** сервером для выполнения аутентичного анализа программного кода и проверки архитектурных инвариантов.

---

## 🏗️ Архитектура системы

Проект разделен на три независимых модуля:
* **`app_day17.py`** — Веб-интерфейс на базе **Streamlit**, предоставляющий чат с агентом, панель управления переходами FSM и отображение доступных инструментов.
* **`agent_day17.py`** — Основной класс-оркестратор (`GuardedFSMAgentWithMCPTools`), который управляет историей сообщений, памятью, защищенными переходами стадий и выступает в роли MCP-клиента.
* **`mcp_server_day17.py`** — Локальный MCP-сервер, реализующий защищенный вызов кастомных инструментов через стандартный ввод-вывод (`stdio`).

---

## 🛠️ Доступные MCP-инструменты

1. **`validate_code_invariants`**:
   * Выполняет глубокий синтаксический анализ с помощью встроенного модуля **`ast`** (Abstract Syntax Tree).
   * Отличает синтаксические ошибки Python от архитектурных дефицитов (например, отсутствие логики конечного автомата FSM или структуры классов/функций).
   * Оснащен надежной системой очистки пользовательских префиксов.
2. **`check_test_status`**:
   * Проверяет статус тест-кейсов, процент покрытия кода (coverage) и количество активных багов для ключевых контуров (`auth`, `payment`, `fsm_agent`).

---

## 🚀 Установка и запуск

1. Убедитесь, что у вас установлены все требуемые зависимости (включая библиотеки `mcp` и `streamlit`).
2. Запустите пользовательский интерфейс через Streamlit:
   ```bash
   streamlit run app_day17.py
   ```
