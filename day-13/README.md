# 🔥 День 13: Состояние задачи (Task State Machine)

Модуль посвящен формализации жизненного цикла задачи в виде конечного автомата (FSM). Ассистент больше не ведет диалог «в вакууме», а точно знает текущий этап разработки, текущий шаг и ожидаемое действие, сохраняя контекст на диске между сессиями.

---

## 🎯 Цели проекта
1. **Конечный автомат задачи (FSM):** Реализация строгой цепочки жизненного цикла: `planning ➔ execution ➔ validation ➔ done`.
2. **Формализованное состояние:** Хранение в рабочей памяти (`working`) трех ключевых параметров: этап (`stage`), текущий шаг (`current_step`) и ожидаемое действие (`expected_action`).
3. **Персистентность и паузы:** Сохранение состояния и истории диалога в JSON-файлах, позволяющее прерывать работу на любом этапе и возобновлять ее без потери контекста.
4. **Умные переходы:** Автоматическое или ручное изменение статусов задачи в зависимости от контекста диалога.

---

## 🛠️ Архитектура и файлы проекта

* **`agent.py`** — Класс `FSMTaskAgent`, управляющий тремя уровнями памяти:
  * `long_term.json` — профиль и стиль ассистента.
  * `working.json` — текущее состояние FSM задачи.
  * `short_term.json` — история последних сообщений диалога.
* **`app.py`** — Веб-интерфейс на базе **Streamlit**, содержащий:
  * Боковую панель управления и мониторинга состояния FSM.
  * Инструменты ручного переключения этапов и шагов.
  * Кнопки полного сброса памяти.
* **`memory_storage_day13/`** — Директория персистентного хранения JSON-данных на диске.

## 🚀 Быстрый старт

1. Установите необходимые зависимости:
   ```bash
   pip install streamlit openai
   ```
2. Убедитесь, что настроена переменная окружения с вашим API-ключом:
```
export LITELLM_API_KEY="ваш_ключ"
```
3. Запустите веб-приложение:
```
streamlit run app.py
```
### 🧪 Сценарий тестирования (Проверка задания)
1. Проверка начального состояния (Planning):
- Сбросьте память через кнопку в сайдбаре. Убедитесь, что задача находится на этапе planning, а ожидаемое действие связано со сбором требований и стека.
2. Проверка переходов (Planning ➔ Execution):
- Отправьте в чат подтверждение (например, «Подтверждаю выбор стека, давай переходить к коду»). Агент автоматически обновит этап FSM на execution.
3. Проверка паузы и возобновления:
- Остановите приложение (Ctrl + C) и закройте вкладку браузера (имитация перерыва).
- Запустите приложение заново (streamlit run app_day13.py).
- Напишите в чат произвольный вопрос без контекста.
- Результат: Агент мгновенно подхватит текущий этап из файла working.json и продолжит работу без необходимости повторных объяснений.

Создан структурированный AI-ассистент с прозрачным жизненным циклом задачи, готовый к интеграции механизмов строгой валидации и инвариантов.
