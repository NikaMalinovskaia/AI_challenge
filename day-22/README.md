# 🤖 День 22: Первый RAG-запрос и Контрольные Бенчмарки

Проект представляет собой реализацию полноценного **RAG-пайплайна** (Retrieval-Augmented Generation) на базе агента. Система умеет индексировать пользовательские документы, производить семантический поиск, генерировать контрольные вопросы для оценки качества, а также запускать ответы модели как с привлечением базы знаний (RAG), так и в изолированном режиме.

---

## 🚀 Основной функционал

1. **Индексация документов**:
   - Поддержка загрузки файлов форматов `.txt`, `.pdf`, `.md`.
   - Выбор стратегии чанкинга (`structural` или `fixed_size`) для оптимального разбиения текстов.
2. **Первый RAG-пайплайн**:
   - Поиск наиболее релевантных фрагментов (чанков) по текстовому запросу пользователя[cite: 4].
   - Интеграция найденного контекста с исходным вопросом[cite: 4].
   - Строгая генерация ответа через LLM (`glm-5.3-flash`) исключительно на основе документов[cite: 4].
3. **Режимы сравнения (С RAG / Без RAG)**:
   - 🔴 **Запрос без RAG**: Модель отвечает опираясь только на свою внутреннюю параметрическую память[cite: 4].
   - 🟢 **Запрос с RAG**: Ответ подкрепляется фактами из документов с прикреплением использованных источников и возможностью просмотра исходных чанков[cite: 3, 4].
   - ⚖️ **Параллельное сравнение**: Одновременный запуск двух режимов для наглядной демонстрации разницы в качестве[cite: 3].
4. **Контрольные бенчмарки (Усиление)**:
   - Автоматическая генерация через LLM мини-набора из **10 контрольных вопросов** по загруженной базе[cite: 4].
   - Фиксация для каждого вопроса **ожиданий** (что именно должно быть в ответе) и **ожидаемых источников**[cite: 4].
   - Надежное сохранение бенчмарков в метаданных индекса (они не затираются при смене стратегий чанкинга)[cite: 4].

---

## 🛠️ Архитектура и структура проекта

- **`app_day22.py`** — пользовательский веб-интерфейс на базе **Streamlit**. Содержит боковую панель с бенчмарками и две основные вкладки: управление индексацией и режим сравнения/тестирования[cite: 3].
- **`agent_day22.py`** — ключевой класс бэкенда (`IndexingAgentDay22`), отвечающий за логику вызовов LLM, оркестрацию RAG-пайплайна и генерацию динамических бенчмарков[cite: 4].
- **`document_indexer.py`** — модуль для извлечения текста из файлов (включая PDF) и применения выбранных стратегий чанкинга[cite: 3, 4].
- **`rag_engine.py`** — поисковый движок для векторного/текстового поиска релевантных фрагментов[cite: 4].

## 📦 Установка и запуск

1. Установите необходимые зависимости (включая Streamlit):
   ```bash
   pip install streamlit
   ```
2. Убедитесь, что вспомогательные файлы (document_indexer.py, rag_engine.py) находятся в корневой директории проекта рядом с app_day22.py и agent_day22.py.
Запустите веб-приложение:
Bash
streamlit run app_day22.py
Откройте в браузере появившуюся ссылку (обычно http://localhost:8501), загрузите документы на первой вкладке и переходите к тестированию RAG-пайплайна
