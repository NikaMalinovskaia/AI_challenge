# AI Challenge - Day 3

## Эксперимент: Сравнение стратегий промптинга

Практическое задание по исследованию того, как разные подходы к составлению промптов влияют на качество ответов языковой модели через корпоративный LiteLLM API.

---

## 🎯 Суть задания
Взять **одну задачу** (в данном случае — классическую логическую задачу о переправе через реку) и решить ее **четырех разных стратегиях промптинга**:
1. **Прямой ответ** — отправка задачи «как есть» без дополнительных инструкций.
2. **Пошаговое решение** — добавление инструкции действовать строго пошагово.
3. **Мета-промпт** — двухшаговый подход, где модель сначала сама генерирует оптимальный системный промпт под задачу, а затем решает её.
4. **Группа экспертов** — ролевое моделирование (Логик, Логистик, Критик), где каждый эксперт оценивает задачу со своей стороны перед финальным ответом.

---

## 📁 Структура проекта

* `task.md` — файл с условием выбранной задачи.
* `main.py` — основной скрипт на Python, который последовательно обращается к LiteLLM API по всем 4 стратегиям и генерирует отчет.
* `run.sh` — bash-скрипт для быстрой настройки окружения и запуска эксперимента.
* `answer_comparison.md` — итоговый Markdown-отчет с ответами модели (создается автоматически после запуска).

---

## 🚀 Инструкция по запуску

### 1. Подготовка
Убедитесь, что у вас установлена библиотека `openai`:
```bash
pip3 install openai
```

## 2. Настройка ключа и модели
- Откройте файл run.sh и впишите ваш личный ключ LiteLLM в переменную LITELLM_API_KEY.
- Откройте файл main.py и укажите точное имя вашей модели (например, полученное через запрос к /v1/models) в переменной MODEL_NAME.

## 3. Запуск
Выполните в терминале команду:
```
bash run.sh
```
После завершения работы скрипта в корневой папке появится файл answer_comparison.md, содержащий подробное сравнение всех ответов.
