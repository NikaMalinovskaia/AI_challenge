# Задача: Переправа через реку

**Условие:**
Крестьянину нужно перевезти через реку волка, козу и капусту. У него есть лодка, в которую помещается только крестьянин, а с ним только один предмет из трех (или волк, коза или капуста). 
Если оставить волка с козой без присмотра, волк съест козу. Если оставить козу с капустой, коза съест капусту. 

Как крестьянину перевезти всю компанию на другой берег? Напишите пошаговый алгоритм.
