# 🤖 AI Challenge — День 7: Персистентный AI-агент с сохранением контекста

Веб-приложение на базе **Streamlit** и **OpenAI API / LiteLLM**, реализующее долгосрочную персистентную память агента. История диалога автоматически сохраняется на диск в JSON-файл и восстанавливается при перезагрузке сессии.

---

## 📂 Архитектура проекта

Проект разделен на логические модули для соблюдения принципов чистого кода:
* **`agent.py`** — класс `LLMAgent`, отвечающий за взаимодействие с LLM (`glm-4.7-flash`), управление историей сообщений, а также за автоматическую сериализацию/десериализацию памяти в JSON (`chat_history.json`).
* **`app.py`** — пользовательский веб-интерфейс на **Streamlit**. Содержит чат-панель, индикатор восстановления контекста, панель отладки с выводом текущего JSON-файла в реальном времени, а также инструменты сброса памяти и генерации отчетов (`agent_output.md`).

---

## ✨ Ключевые возможности

1. **Автоматическая персистентность (Persistence):** Каждое сообщение пользователя и ответ ассистента мгновенно записываются на диск в файл `chat_history.json`.
2. **Восстановление сессии:** При перезапуске приложения или обновлении страницы агент подтягивает прошлый контекст с индикацией успешной загрузки («Контекст успешно восстановлен»).
3. **Панель отладки (Debug View):** В сайдбаре в реальном времени отображается структура JSON-файла истории.
4. **Управление памятью:** Кнопка «Очистить чат и память» полностью сбрасывает контекст и удаляет файл сохранения.
5. **Экспорт отчетов:** Возможность зафиксировать диалог и сохранить его в файл `agent_output.md`.

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей
Убедитесь, что у вас установлен Python (версии 3.9+), затем установите необходимые библиотеки:
```bash
pip install streamlit openai
```
### 2. Настройка переменных окружения
Установите ключ доступа к API (или используйте встроенный дефолтный ключ в коде):
```
export LITELLM_API_KEY="ваш_api_key"
```

### 3. Запуск приложения
Запустите веб-интерфейс с помощью Streamlit:
```
streamlit run app.py
```
После этого приложение откроется в браузере.


## 🧪 Как протестировать (Мануальный сценарий)
- Откройте приложение в браузере. Вы увидите плашку «🆕 Начата новая сессия», так как файл истории еще пуст.  
- Отправьте агенту сообщение (например: «Привет! Запомни кодовое слово: Манго»).  
- Посмотрите в сайдбар в раздел «🔍 Отладка: JSON на диске» — вы увидите, как структура диалога моментально записалась в chat_history.json.  
- Обновите страницу браузера (F5). Вы увидите зеленую плашку 📂 Контекст успешно восстановлен из chat_history.json!
- Задайте проверочный вопрос: «Какое кодовое слово я просил запомнить?». Агент мгновенно ответит «Манго», доказав, что персистентная память работает успешно.
