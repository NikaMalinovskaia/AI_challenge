# 📦 AI Challenge — День 9: Сжатие контекста и Summary

Веб-приложение на базе **Streamlit** и **OpenAI API / LiteLLM**, реализующее интеллектуальное сжатие истории диалога. Старые сообщения суммаризируются в отдельный блок, свежие сообщения сохраняются «как есть», а запросы в модель собираются динамически для максимальной экономии токенов.

---

## 📂 Архитектура проекта

Проект разделен на логические компоненты:
* **`agent.py`** — класс `CompressionAgent`, отвечающий за:
  * Раздельное хранение: поле `summary` хранится на верхнем уровне JSON-файла отдельно от массива сообщений.
  * Стратегию сжатия: деление истории на старые реплики (для суммаризации через LLM) и последние $N$ сообщений («как есть»).
  * Динамическую сборку запроса (`System` + `Отдельное Summary` + `Последние N сообщений`).
  * Бенчмарк-метод `compare_responses`, позволяющий на лету сопоставлять затраты токенов и качество ответов в двух режимах (без сжатия и со сжатием).
* **`app.py`** — пользовательский веб-интерфейс на **Streamlit** с боковой панелью настроек компрессии, отображением отдельного блока сжатого контекста и интерактивным блоком A/B сравнения.

---

## ✨ Ключевые возможности

1. **Раздельное хранение Summary:** Резюме прошлого опыта хранится независимо от массива активных сообщений в JSON-структуре чата на диске.
2. **Сохранение свежего контекста:** Настраиваемое окно ($N$ последних сообщений) всегда передается модели в исходном виде («как есть»), гарантируя абсолютную точность для недавних реплик.
3. **Автоматическое и ручное сжатие:** Возможность задать порог автосжатия по количеству сообщений или нажать кнопку «⚡ Сжать историю сейчас».
4. **Хронологический порядок в Summary:** Специальные инструкции в промпте суммаризации удерживают правильную последовательность событий (что было в начале, фиксируется в первую очередь).
5. **A/B Блок сравнения (Бенчмарк):** Встроенный инструмент тестирования, позволяющий в реальном времени сравнить расход токенов и качество ответов модели *Без сжатия* (вся история) и *Со сжатием* (Summary + $N$).

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей
Убедитесь, что у вас установлен Python (версии 3.9+), затем установите необходимые библиотеки:
```bash
pip install streamlit openai tiktoken
```
### 2. Настройка переменных окружения
Установите ключ доступа к API:
```
export LITELLM_API_KEY="ваш_api_key"
```

### 3. Запуск приложения
Запустите веб-интерфейс с помощью Streamlit:
```
streamlit run app.py
```
После этого приложение откроется в браузере.


## 🧪 Как протестировать (Мануальный сценарий)
- Откройте приложение в браузере и проведите длинный диалог (отправьте 8–10 сообщений на разные темы).
- Нажмите кнопку «⚡ Сжать историю сейчас» в сайдбаре (или дождитесь срабатывания автосжатия по порогу).
- Убедитесь, что:
1. Вверху экрана появился экспандер «📌 Отдельно сохраненный контекст (Summary)» с краткой выжимкой.
2. В ленте чата остались только последние N сообщений «как есть», а старая простыня текста исчезла.
3. Откройте экспандер «🧪 Запустить A/B сравнение (Без сжатия vs Со сжатием)», введите проверочный вопрос (например, о самых первых темах диалога) и нажмите «Сравнить оба варианта»:
4. Сравните расход токенов (вариант со сжатием покажет колоссальную экономию).
5. Оцените качество ответов (модель успешно ответит на вопрос по ранним темам благодаря сохраненному Summary).
