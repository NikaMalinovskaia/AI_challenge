# День 28: Полностью локальная RAG-система и сравнение с облачными LLM

Гибридная RAG-система (Retrieval-Augmented Generation) на базе C# базы знаний по ООП. Приложение объединяет локальный индекс поиска (Retrieval) с локальным инференсом языковой модели (`qwen2.5`), а также предоставляет веб-интерфейс для прямого сравнения отклика, скорости и качества с облачной моделью (`glm-5.3-flash`).

## 🌟 Особенности

* **Локальный Retrieval:** Поиск релевантных документов из локальной базы знаний выполняется на клиенте без передачи данных во внешние сервисы.
* **Гибридный выбор инференса:** Возможность генерировать ответы как полностью офлайн (через Ollama), так и через облачные API для бенчмаркинга.
* **Раздельное управление памятью:** Диалоговая история локальной и облачной сессий изолирована для честного тестирования контекста.
* **Сравнительный бенчмарк (A/B Test):** Модуль параллельного сравнения ответов двух моделей на один и тот же RAG-контекст.

## 🏗️ Архитектура RAG-пайплайна

```
               +----------------------------------+
               |      Запрос пользователя (UI)    |
               +----------------------------------+
                                |
                                v
               +----------------------------------+
               |   Локальный Поиск (Retrieval)    |
               | (по базе знаний C# ООП doc_1..3) |
               +----------------------------------+
                                |
                                v
               +----------------------------------+
               |   Формирование RAG-промпта      |
               |     [Контекст] + [Вопрос]        |
               +----------------------------------+
                                |
        +-----------------------+-----------------------+
        |                                               |
        v                                               v
+-----------------------+                       +-----------------------+
|  Локальная LLM        |                       |  Облачная LLM         |
|  qwen2.5 (Ollama)     |                       |  glm-5.3-flash        |
|  http://localhost:11434|                       |  LiteLLM Proxy API    |
+-----------------------+                       +-----------------------+
```

## 📂 Структура проекта

* `agent_rag.py` — Логика RAG-агента, локального поиска и проксирования запросов к Ollama / OpenAI API.
* `app_rag.py` — Веб-интерфейс на Streamlit с двумя вкладками: интерактивный чат с сохранением истории и сплит-экран для сравнения генераций.

## 🚀 Инструкция по запуску

### 1. Предварительные требования

* **Python 3.8+**
* Запущенный сервис **Ollama** с загруженной моделью:
  ```
  ollama pull qwen2.5
  ```

### 2. Установка зависимостей

```
pip install streamlit requests openai
```

### 3. Запуск веб-приложения

```
streamlit run app_rag.py
```

## 🏆 Вывод

Локальная RAG-система на базе `qwen2.5` показывает полную готовность к автономному использованию в корпоративных или приватных контурах. Использование локального индекса вместе с компактной языковой моделью позволяет давать точные ответы без галлюцинаций и без утечки данных.
