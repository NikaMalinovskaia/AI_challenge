# 🧠 День 11: Модель памяти агента (Tiered Memory Architecture)

Модуль посвящен проектированию и реализации многоуровневой системы памяти для AI-агентов. Мы отходим от единого контекста и разделяем данные на три независимых слоя, хранящихся в изолированных файлах.

---

## 🎯 Цели проекта
1. **Разделение слоев памяти:** Реализация трех классических уровней памяти:
   * **Краткосрочная (`short_term`)** — текущая история диалога.
   * **Рабочая (`working`)** — данные, параметры и контекст текущей задачи.
   * **Долговременная (`long_term`)** — профиль пользователя, стек технологий и постоянные предпочтения.
2. **Явное управление:** Возможность точно выбирать, куда именно сохраняются те или иные данные (через боковую панель управления).
3. **Изолированное хранение:** Каждый тип памяти сохраняется в отдельный JSON-файл на диске, обеспечивая персистентность между сессиями.
4. **Контекстная сборка:** Динамическое формирование системного промпта с включением всех актуальных слоев памяти перед отправкой запроса в LLM.

---

## 🛠️ Архитектура и файлы проекта

* **`agent.py`** — Класс `TieredMemoryAgent`, управляющий раздельной загрузкой, сохранением и сбросом трех типов памяти, а также инъекцией данных в системный промпт.
* **`app.py`** — Интерактивный веб-интерфейс на базе **Streamlit**, содержащий:
  * Настройки модели и параметров генерации (`temperature`).
  * Формы для явного добавления ключей и значений в долговременную и рабочую память.
  * Инструменты очистки диалога (`short_term`) и полного сброса всей памяти.
* **`memory_storage_day11/`** — Директория персистентного хранения JSON-файлов.

## 🚀 Быстрый старт

1. Установите зависимости:
   ```bash
   pip install streamlit openai
   ```
2. Убедитесь в наличии переменной окружения с вашим API-ключом:
```
export LITELLM_API_KEY="ваш_ключ"
```
3. Запустите приложение:
```
streamlit run app.py
```

### 🧪 Сценарий тестирования (Проверка памяти)
1. Заполнение долгосрочной памяти:
- В сайдбаре в блоке «Долговременная (Long-Term)» добавьте параметр: ключ — pref_lang, значение — Python.
2. Заполнение рабочей памяти:
- В блоке «Рабочая память (Working)» добавьте текущую задачу: ключ — current_task, значение — разработка REST API.
3. Проверка ответов:
- Задайте в чате общий вопрос (например: «Набросай базовую структуру проекта»).
- Результат: Агент автоматически учтет, что вы пишете на Python (из долговременной памяти) и делаете REST API (из рабочей памяти), выдав точный и персонализированный результат.
4. Проверка изоляции:
- Нажмите «🧹 Очистить краткосрочную память». История диалога сотрется, но сохраненные в долговременную и рабочую память данные останутся на месте.

### 🏆 Результат
Создана устойчивая многоуровневая архитектура памяти, которая позволяет агенту сохранять контекст задач и профиль пользователя независимо от длины диалога.
