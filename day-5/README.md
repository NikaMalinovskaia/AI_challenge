# 🚀 День 5: Сравнение версий моделей с LiteLLM

Этот проект представляет собой Python-скрипт для автоматизированного тестирования и сравнения трех разных моделей ИИ (слабой, средней и сильной) с использованием библиотеки **LiteLLM**. 

Скрипт отправляет один и тот же тестовый промпт на все выбранные модели, производит замеры ключевых метрик (время ответа, точное количество токенов, стоимость) и автоматически генерирует **два аналитических файла** с результатами.

---

## 🛠 Стек технологий

* **Python 3.10+**
* **LiteLLM** (универсальный SDK для работы с LLM-провайдерами)
* **Python-dotenv** (для работы с переменными окружения)

---

## 📁 Структура проекта

* `main.py` — основной и единственный исполняемый скрипт, содержащий всю логику запросов, замеров и генерации отчетов.
* `.env` — файл с вашими API-ключами (создается вручную).
* `day5_analysis_report.md` — генерируемый скриптом технический отчет с таблицей метрик и ответами моделей.
* `day5_comparison_summary.md` — генерируемый скриптом файл со сравнительным анализом (скорость, ресурсоёмкость, качество).

---

## ⚙️ Установка и запуск

### 1. Установите зависимости
Убедитесь, что у вас установлен Python, затем выполните команду в терминале:
```bash
pip install litellm python-dotenv
```

## 2. Настройте ключи API
Создайте файл .env в корневой директории проекта и добавьте туда ключ вашего провайдера (например, DeepSeek, OpenAI или другие, поддерживаемые LiteLLM):
Фрагмент кода
```
DEEPSEEK_API_KEY=your_actual_api_key_here
```

## 3. Запустите скрипт
```
python main.py
```
После завершения работы скрипта в папке проекта появятся два готовых Markdown-файла с результатами экспериментов.
