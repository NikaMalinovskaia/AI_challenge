# 🔗 День 19. Композиция MCP-инструментов (Пайплайн данных)

Учебный проект по созданию автономного многошагового ИИ-агента с оркестрацией через Model Context Protocol (MCP) и жесткой цепочкой выполнения задач (**ReAct-loop**).

---

## 🚀 Архитектура проекта

Проект состоит из трех основных модулей, обеспечивающих поиск, глубокую обработку и гарантированное сохранение результатов:

1. **`agent_day19.py`** — Интеллектуальный оркестратор (ReAct-агент), управляющий циклом выполнения задач, защищенный автономным режимом (фоллбэком) при сетевых ограничениях.
2. **`mcp_server_day19.py`** — Набор MCP-инструментов (Tools):
   - `search_tool`: Поиск информации в реальном времени (интеграция с Wikipedia API) с поддержкой локального банка знаний.
   - `summarize_tool`: Глубокая обработка, очистка и синтез собранных данных в структурированный аналитический отчет.
   - `save_file_tool`: Безопасное сохранение итоговых отчетов в уникальные файлы на диске.
3. **`app_day19.py`** — Интерактивный пользовательский интерфейс на базе **Streamlit** для управления агентом в реальном времени.

---

## 🛠️ Основные возможности

* **Строгий пайплайн (3 шага):** Автоматическая последовательность `Search ➔ Summarize ➔ SaveToFile`. Агент не может завершить работу без сохранения файла.
* **Гибридный поиск:** Поиск свежих данных в интернете через Wikipedia API с возможностью автоматического переключения на локальную базу данных при сетевых ограничениях среды.
* **Динамическое именование файлов:** Автоматическая генерация уникальных и безопасных имен файлов на основе темы запроса пользователя (сохраняются в директорию `pipeline_results_day19/`).
* **Отказоустойчивость:** Автономный режим оркестрации, гарантирующий выполнение цепочки и сохранение отчета даже в полностью изолированных средах.

## 📂 Структура каталогов

```text
AI-19/
│
├── agent_day19.py          # Логика агента и оркестрация пайплайна
├── mcp_server_day19.py     # Реализация MCP-инструментов (поиск, суммаризация, сохранение)
├── app_day19.py            # Веб-интерфейс (Streamlit)
├── pipeline_results_day19/ # Директория с сохраненными аналитическими отчетами
└── memory_storage_day19/   # Хранилище краткосрочной памяти агента
```
## ⚙️ Установка и запуск
1. Установите необходимые зависимости (openai, streamlit и др.):
```
pip install openai streamlit
```
2. Запустите веб-интерфейс приложения через Streamlit:
```
streamlit run app_day19.py
```
3. В появившемся окне введите интересующую вас тему (например: «Сделай аналитический отчет про Искусственный интеллект») и наблюдайте за выполнением многошагового пайплайна!
