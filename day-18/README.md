# День 18: Автономный ИИ-агент с фоновым планировщиком (24/7 Scheduler) и MCP

Проект представляет собой развитие архитектуры ИИ-агентов с интеграцией **Model Context Protocol (MCP)** и фонового планировщика для автоматического сбора и мониторинга метрик качества программного обеспечения.

## 🚀 Архитектура и особенности

1. **Фоновый планировщик и динамические метрики**:
   - Автоматически отслеживает и собирает показатели качества (покрытие кода тестами, количество багов).
   - Динамически обновляет историю метрик при запросах сводки, имитируя непрерывную работу фоновых проверок 24/7.
2. **Интеграция с MCP (Model Context Protocol)**:
   - Использование стандартизированного сервера для изоляции логики работы с данными (`mcp_server_day18.py`).
   - Набор инструментов: `collect_and_store_metrics` и `get_periodic_summary`.
3. **FSM (Конечный автомат) и Guardrails**:
   - Контроль жизненного цикла задач по этапам (`planning` ➔ `execution` ➔ `validation` ➔ `done`).
4. **Интерфейс Streamlit**:
   - Удобный веб-интерфейс для взаимодействия с агентом в режиме реального времени.

---

## 📂 Структура проекта

* `app_day18.py` — веб-интерфейс на базе Streamlit.
* `agent_day18.py` — логика FSM-агента, управление историей и вызов MCP-инструментов.
* `mcp_server_day18.py` — MCP-сервер, реализующий инструменты сбора метрик и фонового мониторинга.
* `metrics_history.json` — локальное хранилище истории метрик и фоновых тиков.

---

## 🛠️ Установка и запуск

1. Убедитесь, что у вас установлены все необходимые зависимости (включая библиотеки для работы со Streamlit и MCP):
   ```bash
   pip install streamlit mcp openai
   ```
2. Запустите веб-приложение через Streamlit:
```
streamlit run app_day18.py
```
3. Откройте в браузере появившуюся ссылку (обычно http://localhost:8501) и протестируйте работу агента:
- Отправьте запрос на сбор метрик для конкретной фичи (например: "Собери метрики для фичи authentication").
- Запросите регулярную сводку (написав "Покажи сводку"), чтобы увидеть динамически обновляющуюся историю с таймстампами.
