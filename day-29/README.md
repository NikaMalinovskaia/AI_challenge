# День 29: Оптимизация локальной LLM под конкретную задачу

В этом модуле мы переходим к глубокой тюнинг-оптимизации локальной языковой модели (`qwen2.5` через Ollama) для узкоспециализированной задачи — **экспертного код-ревью и обучения ООП на C#**. 

Мы настроили гиперпараметры генерации, ограничили окно контекста, создали специализированные системные промпт-шаблоны и реализовали встроенный бенчмарк для сравнения производительности «до» и «после» оптимизации.

---

## 🎛️ Ключевые направления оптимизации

### 1. Тюнинг гиперпараметров (Ollama Options)
* **`temperature` (Креативность/Точность):** Снижена с дефолтных `0.7–0.8` до `0.2` для технических задач. Это убирает «галлюцинации» модели и заставляет её строго следовать кодовой базе и принципам ООП.
* **`num_predict` (Max Tokens):** Жесткое ограничение максимального числа генерируемых токенов (например, `400`). Защищает от бесконечных рассуждений и ускоряет ответ.
* **`num_ctx` (Context Window):** Оптимизация размера окна контекста (`2048` токенов), что снижает потребление оперативной памяти и нагрузку на процессор/GPU.

### 2. Кастомизация промпт-шаблонов (Prompt Engineering)
Вместо размытых запросов внедрены специализированные роли:
* **«Строгий код-ревьюер»:** Фокусируется на аудите кода, выявлении нарушений инкапсуляции (например, публичных полей вместо свойств) и предоставлении лаконичных исправлений.
* **«Преподаватель-наставник»:** Объясняет концепции простым языком, добавляет жизненные аналогии и короткие фрагменты кода.

---

## 📂 Структура проекта

* `agent_rag.py` — Расширенный класс `LocalRAGAgent`, поддерживающий управление параметрами `temperature`, `max_tokens` и динамические промпт-шаблоны.
* `app_rag.py` — Веб-интерфейс на Streamlit, разделенный на интерактивный чат с настраиваемыми ролями и вкладку **«Бенчмарк оптимизации»**.

---

## 🚀 Инструкция по запуску

### 1. Установка зависимостей
Убедитесь, что установлены необходимые библиотеки Python:
```
pip install streamlit requests openai
```

### 2. Запуск приложения
Запустите веб-панель оптимизации командой:
```
streamlit run app_rag_2.py
```
