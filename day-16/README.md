🚦 День 16: Подключение Model Context Protocol (MCP)
На этом этапе мы расширяем возможности агента, подключая его к внешним инструментам через стандарт Model Context Protocol (MCP). Агент не просто генерирует текст, а инициализирует реальное клиентское соединение с MCP-сервером и динамически запрашивает список доступных инструментов.
🎯 Цели проекта
Инициализация MCP-клиента: Настройка асинхронного соединения со стандартизированным MCP-сервером через stdio_client и ClientSession.   
PY
Динамическое получение инструментов: Запрос списка доступных инструментов с сервера при помощи метода session.list_tools().   
PY
Визуализация в интерфейсе: Вывод полученного списка инструментов в боковой панели веб-интерфейса Streamlit для наглядного контроля.   
PY
Интеграция с агентом: Добавление описаний инструментов в системный промпт LLM, чтобы агент знал о доступных возможностях.   
PY
🛠️ Архитектура и файлы проекта
agent_day16.py — Класс GuardedFSMAgentWithMCP, объединяющий логику конечного автомата (FSM), работу с памятью и асинхронный метод fetch_mcp_tools(), который поднимает сервер @modelcontextprotocol/server-everything и возвращает список доступных инструментов.   
PY
app_day16.py — Веб-интерфейс на базе Streamlit с боковой панелью управления состоянием FSM и блоком динамического отображения MCP-инструментов в реальном времени.   
PY
🚀 Быстрый старт
Установите зависимости (включая SDK MCP):
Bash
pip install streamlit openai mcp
Убедитесь, что у вас настроена переменная окружения с API-ключом:
Bash
export LITELLM_API_KEY="ваш_ключ"
Запустите веб-приложение:
Bash
streamlit run app_day16.py
🧪 Сценарий тестирования (Проверка задания)
Проверка установки соединения и загрузки инструментов:
Запустите приложение командой streamlit run app_day16.py.   
PY
Посмотрите на боковую панель (sidebar) слева. В разделе «📦 Доступные MCP инструменты» должен отображаться автоматически подгруженный список инструментов от сервера.   
PY
Результат: Соединение успешно установлено, а список инструментов корректно возвращен и выведен в интерфейс.
