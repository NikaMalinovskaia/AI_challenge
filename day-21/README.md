# 📚 День 21. Локальный пайплайн индексации документов и сравнение стратегий Chunking

Проект представляет собой модульное приложение на базе **Python** и **Streamlit** с функционалом автономного ИИ-агента для загрузки, обработки, интеллектуального разбиения (chunking) и индексации документов различных форматов (PDF, Markdown, TXT, Python-код).

---

## 🚀 Основные возможности

1. **Множественные форматы файлов:** Поддержка загрузки текстовых файлов, кода и PDF-документов с автоматическим извлечением текста и разбивкой по страницам.
2. **Две стратегии чанкинга:**
   * **Фиксированный размер (`fixed_size`):** Разбиение текста на блоки заданного размера с перекрытием (`overlap`).
   * **По структуре (`structural`):** Умное разделение по абзацам/страницам с автоматической генерацией смысловых заголовков (тем) для каждого отрывка.
3. **Метаданные чанков:** Каждый чанк обогащается полным набором метаданных (`chunk_id`, `source`, `strategy`, `section` / тема, `embedding_stub`).
4. **Интерактивный аналитический блок:** Параллельное сравнение обеих стратегий на вашем корпусе документов с автоматическим расчетом средних длин чанков, степени фрагментации и выдачей экспертных рекомендаций.
5. **Сохранение индекса:** Экспорт готового структурированного векторного индекса в локальное хранилище в формате JSON (`vector_index.json`).

---

## 🛠️ Структура проекта

* `app_day21.py` — веб-интерфейс на **Streamlit** (управление загрузкой файлов, запуск пайплайна, вкладки индексации и сравнения).
* `agent_day21.py` — класс агента-оркестратора (`IndexingAgentDay21`), управляющий логикой индексации и генерацией аналитических отчетов.
* `document_indexer.py` — движок индексации (`DocumentIndexer`), реализующий алгоритмы чтения PDF (`pypdf`), чанкинга и сохранения индекса.

## 📦 Установка и запуск

### 1. Клонирование / подготовка репозитория
Убедитесь, что у вас установлены Python 3.9+ и pip.

### 2. Установка зависимостей
Установите необходимые библиотеки (Streamlit и утилиту для работы с PDF):

```bash
pip install streamlit pypdf
```
(Если в системе команда pip не найдена, используйте python3 -m pip install streamlit pypdf)

### 3. Запуск приложения
Запустите графический интерфейс командой:
```
streamlit run app_day21.py
```
После этого в браузере автоматически откроется страница приложения.

## 📖 Как пользоваться
1. Загрузите документы: В боковой панели (Sidebar) перетащите один или несколько PDF-файлов, текстов или скриптов. Система мгновенно покажет статус готовности, размер в КБ и количество символов.
2. Индексация по стратегии: На вкладке «🚀 Индексация по одной стратегии» выберите метод чанкинга (Fixed Size или Structural) и нажмите кнопку «Запустить индексацию корпуса». Вы сможете детально изучить содержимое и метаданные каждого сохраненного чанка.
3. Сравнение стратегий: Перейдите на вкладку «⚖️ Сравнение стратегий», чтобы запустить параллельный анализ, увидеть экспертный отчет системы и сравнить, как один и тот же текст разбивается разными алгоритмами.
