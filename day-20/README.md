# 🌐 День 20. Мультисерверная оркестрация MCP (Orchestration MCP)

Учебный проект по созданию автономного агента, способного координировать работу нескольких независимых Model Context Protocol (MCP) серверов, выполнять длинные кросс-серверные сценарии (workflows) и обеспечивать фоновый мониторинг системы в режиме 24/7.

---

## 🚀 Архитектура проекта

Проект разделен на изолированные микросервисы и оркестратор:

1. **`mcp_server_analytics.py`** — Сервер аналитики (`AnalyticsServer`), отвечающий за сбор системных метрик и показателей покрытия кода.
2. **`mcp_server_crm.py`** — Сервер CRM (`CRMServer`), предоставляющий инструменты для создания тикетов в Jira и отправки уведомлений в Slack.
3. **`agent_day20.py`** — Интеллектуальный оркестратор (`OrchestrationAgentDay20`), который маршрутизирует запросы пользователя, запускает длинные цепочки действий с разных серверов и управляет фоновым потоком планировщика.
4. **`app_day20.py`** — Интерактивный веб-интерфейс на базе **Streamlit** для управления агентом, мониторинга статуса и просмотра отчетов.

---

## 🛠️ Основные возможности

* **Мультисерверная оркестрация:** Регистрация и одновременное использование нескольких независимых MCP-серверов в рамках единого пайплайна.
* **Длинные сценарии (Long Workflows):** Последовательное выполнение связанных задач (`Search Metrics ➔ Create Jira Ticket ➔ Send Slack Notification`).
* **Фоновый планировщик (24/7):** Фоновый поток (`Background Scheduler`), который автоматически опрашивает серверы, проверяет состояние системы и сохраняет актуальные отчеты в директорию `background_reports/`.
* **Интерактивный дашборд:** Отображение статуса фоновых задач в сайдбаре и удобное управление историей диалога.

## 📂 Структура каталогов

```text
AI-20/
│
├── agent_day20.py            # Логика оркестратора и фоновый поток
├── mcp_server_analytics.py   # MCP-сервер аналитики и метрик
├── mcp_server_crm.py         # MCP-сервер CRM (Jira, Slack)
├── app_day20.py              # Веб-интерфейс Streamlit
├── background_reports/       # Автоматические фоновые отчеты 24/7
└── memory_storage_day20/     # Краткосрочная память агента
```
## ⚙️ Установка и запуск
1. Установите необходимые зависимости (openai, streamlit, mcp):
```
pip install openai streamlit mcp
```
2. Запустите веб-интерфейс приложения через Streamlit:
```
streamlit run app_day20.py
```
3. Откройте локальную ссылку в браузере и протестируйте кросс-серверный флоу, отправив в чат запрос:
- «Запусти полный флоу по платежам»
- «Нужно проверить метрики и создать задачу для фичи авторизации»
