# 🚀 RAG Agent: День 23 — Реранкинг, Фильтрация и Query Rewrite

Проект представляет собой продолжение разработки интеллектуального RAG-агента (Дни 21–22)[cite: 5, 6, 7]. В **День 23** внедрен критически важный слой оптимизации и контроля качества поиска: **пороговая фильтрация (similarity threshold)**, **двухэтапный отбор (Top-K initial vs final)** и **интеллектуальное переформулирование запросов (Query Rewrite)**.

---

## 📌 Архитектура и новые возможности

1. **Query Rewrite (Переформулирование запроса):**
   * Перед поиском в базе данных запрос пользователя оптимизируется с помощью LLM для максимального совпадения с терминологией в документах.
2. **Метрика релевантности (Similarity Score):**
   * Каждому найденному фрагменту текста присваивается математическая оценка совпадения (`score`), что позволяет оценивать качество каждого чанка[cite: 5].
3. **Пороговая фильтрация (Similarity Threshold):**
   * Инструмент отсекает «информационный шум» и нерелевантные фрагменты, защищая языковую модель от галлюцинаций.
4. **Гибкое управление Top-K:**
   * Разделение на первичный поиск (`Top-K до фильтрации`) и финальную выборку контекста (`Top-K после фильтрации`).
5. **Сравнительный анализ:**
   * Возможность в один клик сравнить ответы модели в режиме *«Без фильтра и rewriting»* против *«С фильтром, реранкингом и rewriting»*.

---

## 🛠️ Структура проекта

* **`agent_day23.py`** — основной класс бэкенда агента, реализующий логику `rewrite_query`, расчет скоров и двухэтапную фильтрацию.
* **`rag_engine.py`** — поисковый движок векторной базы данных с расчетом метрик релевантности чанков[cite: 5].
* **`document_indexer.py`** — модуль загрузки, обработки и чанкинга документов (поддерживает структурный и фиксированный подходы)[cite: 5, 7].
* **`app_day23.py`** — интерактивный веб-интерфейс на базе **Streamlit** с боковой панелью настроек и блоками мониторинга отсеянных чанков[cite: 5, 7].

## 📦 Установка и запуск

1. Убедитесь, что у вас установлены все необходимые библиотеки:
   ```bash
   pip install streamlit
   ```
2. Запустите веб-приложение через Streamlit:
Bash
streamlit run app_day23.py
Откройте в браузере появившуюся ссылку (обычно http://localhost:8501).
⚙️ Как пользоваться приложением
Вкладка «1. Индексация и Бенчмарки»:
Загрузите ваши текстовые файлы (.txt, .pdf, .md).   
JPG
Выберите стратегию чанкинга (structural или fixed_size) и нажмите «Запустить индексацию»[cite: 7].
Сгенерируйте автоматические контрольные вопросы для проверки базы знаний[cite: 7].
Вкладка «2. Улучшенный RAG и Сравнение»:
Настройте параметры в боковой панели: включите порог релевантности, отрегулируйте ползунок threshold и активируйте Query Rewrite[cite: 7].
Введите вопрос или воспользуйтесь контрольными вопросами из сайдбара[cite: 7].
Используйте кнопку «Сравнить: Без фильтра/rewriting vs С фильтром» для наглядной оценки прироста качества[cite: 7].
